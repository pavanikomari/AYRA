📌 About the Project

AYRA is a women empowerment platform designed to support, educate and empower women by providing access to useful resources, opportunities and digital services.

The platform aims to encourage women's independence, confidence, education, skill development and personal growth through technology.

AYRA provides a user-friendly and accessible digital environment where women can explore opportunities, access valuable information and connect with empowerment initiatives.

🎯 Project Objectives

- Promote women's education and awareness.
- Encourage financial and digital independence.
- Provide access to career and skill development resources.
- Create awareness about women's rights and opportunities.
- Support personal and professional growth.
- Build an accessible and user-friendly empowerment platform.

🏗️ Project Architecture

AYRA follows a full-stack architecture.

1. Frontend: Provides the user interface and interactive experience.
2. Backend: Node.js and Express handle API requests and business logic.
3. Database: Supabase PostgreSQL stores application data.
4. Authentication: Supabase Auth manages user authentication.

⚙️ Installation and Setup

Prerequisites

- Node.js
- npm
- Supabase account
- Antigravity IDE or VS Code

Step 1: Clone the repository

git clone YOUR_REPOSITORY_URL

Step 2: Open the project

cd AYRA

Step 3: Install backend dependencies

cd backend
npm install

Step 4: Configure environment variables

Create a ".env" file inside the backend folder.

PORT=5000
SUPABASE_URL=your_supabase_project_url
SUPABASE_KEY=your_supabase_publishable_key

Add the actual credentials locally. Never upload private credentials to GitHub.

Step 5: Start the backend

npm start

Step 6: Run the frontend

Run the frontend using your configured development server or local development setup.
